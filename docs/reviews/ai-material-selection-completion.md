## 4. 실호출로 찾아 고친 결함

| 관찰 | 원인 | 수정 |
|---|---|---|
| 요청하지 않은 과제 수행 항목("과제 보고서 초안 작성") | 프롬프트가 과제 마감만 알리고 금지 예시가 없었다 | 계획·선택 프롬프트에 금지/허용 예시, 미완료 과제 구간 표시 |
| 지정 자료를 무시하고 첫 미학습으로 감 | 선택 프롬프트가 지정 자료를 "먼저 검토"로만 말했다 | "이번 계획의 중심, 반드시 고른다" |
| 저장된 요청의 날짜가 배열로 들어감 | ObjectMapper 날짜 직렬화 기본값 | `WRITE_DATES_AS_TIMESTAMPS` 끔 |
| "개념부터"가 일반 503(E503_002)으로 끝남 | 개념 자료가 없는 과목에서 모델이 항목 0개를 냈고 서버가 호출 실패와 같은 코드로 보고 | 항목 없는 계획을 `E503_005`로 구분(빈 초안 저장 없음), "과제만 남아 보여도 개념·연습 항목을 만든다" 규칙 |
| 다시 만든 초안에 과제 A 구현 항목 | 과제 행이 구간만 가리켜(topicId 없음) 첫 미학습 항목에 과제 표시가 없었다 | 과제 구간에 연결된 학습 항목에도 "미완료 과제의 항목" 표시 + 규칙 |
| 선택 이유에 없는 "지정 자료" | 규칙 문장이 조건 없이 지정 자료를 말했다 | 요청에 지정 자료가 있을 때만이라고 한정 |
| 6과목에서 검토하지 못한 범위가 같은 주차 이름으로 겹쳐 보임 | 화면이 프로젝트 이름을 뺐고, 요약만 본 묶음도 "목록으로도 보지 못함"이라 함 | 여러 프로젝트면 이름을 붙이고, 요약만 본 범위는 따로 말함 |
| 상담 초안 제목이 이전 자료함 진입 범위("자료구조")로 보임 | 계획 화면에 남은 범위 상태 | 상담 초안이 오면 범위·지정 자료를 비우고 제목은 초안의 범위로 |
| 판단 사실만으로 입력이 커질 때 상한 없음 | 경고 로그 뒤 그대로 호출 | 선택 32,000 / 계획 48,000을 넘으면 호출하지 않고 400 `E400_034` |

"지금 초안은 그대로"와 서버 안내를 보인다.
