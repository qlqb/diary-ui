### 화면에서 찾아 고친 결함

1. 방금 만든 초안이 곧바로 "갱신 필요"로 보임 — 서버가 생성 직후 합의에 초안 id를 적으며 판 번호를 올림. 서버가 "초안 저장 뒤에
   바뀐 합의 항목"으로 판단하도록 고침(API `5acf4ab`, 회귀 테스트 추가).
2. 초안 뒤에 한마디만 더 해도 새로고침에 초안이 사라짐 — 복구가 마지막 메시지만 봄. 가장 최근 초안 메시지에서 복구하도록 고침
   (`AiPanelConsult.test.jsx` "새로고침 뒤 초안 복구").
3. "꼭 하는 이유"가 늘 "기록되지 않았어요" — 이유가 근거 기록에만 있었음. 서버가 항목 응답에 `selectionReason`·`origin`을 붙임.

## 4. 하지 않은 것·알려진 한계

- **시각 확인 미완**: 스크린샷을 찍지 못했다(위). 간격·대비·모바일 키보드가 실제로 뜬 상태의 가림은 사람 눈으로 확인이 필요하다.
- 자료의 쪽·슬라이드·셀로 곧장 이동하지 않는다(파일은 blob으로 통째로 열린다). 카드는 "이 위치를 열어서 확인해 주세요: 셀 2~4"라고 말한다.
- 편집 충돌에서 "내 값/새 제안" 고르기는 예상 시간만 된다. 다른 필드는 유지된 내 값과 제안을 나란히 보여 주기만 한다.
- "못 했음"을 기록하는 서버 경로가 없다(부분 수행은 1~99%). 걸린 점은 "일부 했어요"·"완료"에서만 고른다.
- 작업 공간의 "이 초안 버리기"는 화면에서만 닫는다(폼과 같은 기존 동작).
- 계획 탭 대화는 이제 scope=PLAN으로 만든다 — 예전에 "전체" 범위로 시작한 계획 탭 대화는 이 목록에 보이지 않는다(대화 목록의 다른 범위에는 남아 있다).
- 700px 미만 하단 탭바에 항목이 7개(탭 6 + 로그아웃)다.
- 질문 피로도·"이해가 맞았다"는 체감·설명 반복 감소는 기능 테스트로 검증되지 않는다. 실제 사용 뒤 의견으로 평가한다.
- `src/views/learning/LearningMap.jsx`(옛 지도)는 남아 있지만 아무 데서도 쓰지 않는다.
